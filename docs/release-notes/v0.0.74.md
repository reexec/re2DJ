# re2DJ v0.0.74

## 변경 사항

- CHD가 HDD에 있을 때 곡 로딩이 빨라집니다. 게임이 읽은 파일을 overlay 폴더의 `.re2dj-readahead`에 기억해 두었다가, 다음 실행부터 여러 번 쓰인 파일(패널, 이펙트, 랭킹, 폴더 목록 등)을 게임이 한가할 때 미리 읽습니다. 같은 모드로 여러 곡을 한 뒤부터 효과가 납니다. 캐시를 비운 HDD에서 6th 데모의 곡 로딩이 2.17초에서 0.58초로 줄었습니다.
- Windows in-process 러너가 가벼워졌습니다. import 호출마다 하던 이름 검색과 DirectDraw `Clear`의 불필요한 복사를 없애, vsync를 끈 처리량이 게임에 따라 6~43%, `Clear`를 쓰는 게임은 그 위에 17~26% 올랐습니다. 기본 설정(60fps)에서는 CPU 사용량이 줄어듭니다.
- `--vsync on|off|adaptive` 옵션을 더했습니다. 기본값은 on이고, off는 최대 처리량을 잴 때 씁니다.

## English

# re2DJ v0.0.74

## Changes

- Song loading is faster with the CHD on a hard disk: the files the game reads are remembered in `.re2dj-readahead` in the overlay folder, and from the next run those used more than once (panels, effects, rankings, directory listings and the like) are read ahead while the game is idle. It helps once several songs have been played in the same mode; with the caches emptied, 6th's demo song loads fell from 2.17 s to 0.58 s.
- The Windows in-process runner is lighter: the by-name lookup every import call made and DirectDraw `Clear`'s needless copying are gone, raising vsync-off throughput by 6 to 43% per game and by 17 to 26% more for games using `Clear`; at the default (60 fps) it uses less CPU.
- A `--vsync on|off|adaptive` option; on is the default, off is for measuring peak throughput.

## Resolved issues

- [#24](https://github.com/reexec/re2DJ/issues/24) Remember the CHD paths read and read them ahead in later runs (song-load stalls on an HDD) — no PR (local merge)
- [#25](https://github.com/reexec/re2DJ/issues/25) Cut the in-process runner's import path and DirectDraw Clear costs, and a --vsync option — no PR (local merge)

## Validation

- Windows x86 Debug (6,438 unit checks, 0 failures, 4 CTest tests), Release, and WSL Linux x64, x86 and clang (warnings as errors, 5 CTest tests each)
- On Windows: 6th's song loads timed from an HDD with the caches emptied, vsync-off throughput of five targets measured with the builds before and after alternating, and 4th and 6th at 60 fps with no warnings at the default

Original game executables, HDD data, CHD images and Hardlock material (`cfg/`) are not included in release packages.
